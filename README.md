# AI-generated design renderings — Study 1 AI image Generation

Supporting images for the manuscript *AI-generated Images in Design Education: Performance,
Perception, and Cognitive and Visual Mechanisms*.

The prompts are in **`Study 1 AI Image Generation/Prompts.docx`**, and every image file is named so
that it maps directly onto a row of that table.

## Coverage

The Study 1 design is 5 themes x 3 camera views x 5 outputs x 5 tools = **375** AI-generated
images. Every other tool folder is complete at 15 images per theme, 75 per tool. Raw generation batches,
alternates, and exploratory outputs present in the working folders are not published; only the
images belonging to the documented design are included.

## Image processing

JPEG, quality 92, 4:4:4 chroma, longest side capped at 1920 px; smaller originals were not
upscaled. These are derived files for browsing and reference; lossless originals are not in this
repository.


## Study 2 Experiment

`Study 2 Experiment/` holds the stimulus images and the PsychoPy script used in the Study 2
rating task.

| Path | Contents | Files |
|---|---|---|
| `Study 2 Experiment/AI/` | AI-generated renderings, `1.png` to `20.png` | 20 |
| `Study 2 Experiment/Human/` | Human-made renderings, `0.png` to `20.png` | 21 |
| `Study 2 Experiment/image_rating_task.py` | PsychoPy presentation and response-logging script | 1 |

AI image numbers map onto tools in blocks of four:

| Files | Tool | Code in the response log |
|---|---|---|
| `AI/1.png` to `AI/4.png` | Midjourney | `MJ` |
| `AI/5.png` to `AI/8.png` | SketchUp Diffusion | `SDU` |
| `AI/9.png` to `AI/12.png` | Stable Diffusion | `SD` |
| `AI/13.png` to `AI/16.png` | Stable Diffusion with a fine-tuned LoRA model | `LoRA` |
| `AI/17.png` to `AI/20.png` | GPT-4o | `GPT` |

`Human/0.png` is the practice image shown first to every participant and is not scored.

Each participant saw 20 scored images: 2 of the 4 images from each AI tool (10 AI) and 10 of the
20 human-made images, in random order. Each image stayed on screen for 10 s, followed by three
questions answered with the mouse: a 0 to 100 quality rating, "Do you like this image?" (Yes/No),
and "Do you think this image is generated by AI?" (Yes/No). A 10 s fixation cross separated trials.

The `Image#` column in the response log is a zero-based index, so `Image# = j` refers to file
`j+1.png`. For example, `AI/ 0 MJ` is `AI/1.png`.

The files are the ones shown in the experiment, pixel for pixel. Embedded metadata (generator
account names, prompts, links, EXIF) was removed. The human-made files are JPEG-encoded despite
the `.png` extension; the names were kept so the script runs without changes. Participant
response logs are not published.
